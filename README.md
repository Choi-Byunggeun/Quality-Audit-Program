# 품질심사 일정 계획 관리 시스템 (Quality-Audit-Program)

항공정비 품질심사 일정 계획 및 관리 자동화 웹 애플리케이션입니다.

## 🚀 주요 기능
- **심사 일정 자동 최적화 배치**: 심사 주기, 심사원 자격 요건, 출장 및 업무 일정 등을 고려한 자동 스케줄링
- **심사원 관리 및 심사 이력 관리**: 자격증, 심사원별 역할, 과거 심사 이력 데이터베이스 연동
- **인터랙티브 웹 대시보드**: 간트 차트, 달력 뷰, 지도 기반 국내/해외 공항 시각화
- **엑셀(Excel) 데이터 연동**: 기존 엑셀 심사 계획표 및 실시 이력 파일 업로드/다운로드 지원

## 🛠 실행 방법
1. 필요 패키지 설치:
   ```bash
   pip install -r requirements.txt
   ```
2. 웹 서버 구동:
   ```bash
   python app.py
   ```
   또는 `run.bat` 실행
3. 브라우저에서 `http://localhost:8000` 접속
